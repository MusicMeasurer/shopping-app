# ShoppingApp · v0.0.1

Первый прототип списка покупок на русском языке для iPhone: React, TypeScript, Vite, PWA и IndexedDB. Только бесплатные зависимости; сервер, аккаунт и внешние сервисы не требуются.

## Возможности

- Два независимых списка: «Продукты» и «Хозяйственные покупки».
- Добавление названий до 120 символов, отметка/снятие отметки покупки и удаление.
- Купленные товары переходят вниз списка.
- Данные сохраняются в IndexedDB текущего браузера. Неуспешное сохранение отображает ошибку.
- Установка на домашний экран и работа без сети после первого успешного открытия и кеширования приложения.

## Запуск

Нужен Node.js 22.12+ (проверено с Node.js 24) и npm.

```sh
npm ci
npm run dev
```

Откройте http://localhost:5173/shopping-app/. Dev-сервер предназначен для разработки; service worker создаётся при сборке.

```sh
npm run build
npm run preview
```

Готовая сборка находится в `dist/`, локальная проверка — http://localhost:4173/shopping-app/. Настроен базовый путь `/shopping-app/`, manifest и service worker ограничены этим путём. Автоматическая публикация и настройка GitHub Pages отсутствуют.

## Проверки

```sh
npm test
npm run build
npx playwright install --with-deps webkit chromium
npm run test:e2e
```

Модульные тесты проверяют валидацию, разделение списков и сохранение/изменение/удаление через повторное открытие IndexedDB. Браузерный тест запускает production-сборку в WebKit и Chromium с размером экрана iPhone 13 и проверяет покупки, переключение, сохранение после перезагрузки, manifest и работу без сети. Это эмуляция, реальное устройство необходимо проверить отдельно.

## Первое тестирование на iPhone

1. Для проверки без публикации запустите `npm run dev` на компьютере в одной Wi-Fi сети с iPhone. Откройте в Safari `http://<локальный-IP-компьютера>:5173/shopping-app/`. Так можно проверить интерфейс и IndexedDB, но PWA и офлайн через обычный HTTP на телефоне не работают.
2. Для полноценного теста PWA нужен **HTTPS**. После отдельного решения о публикации можно разместить содержимое `dist/` на GitHub Pages по адресу `https://musicmeasurer.github.io/shopping-app/`. Эта версия не публикует сайт и не меняет Pages. Альтернатива — собственный локальный HTTPS-сервер с доверенным на iPhone сертификатом, обслуживающий сборку по `/shopping-app/`.
3. Откройте HTTPS-адрес в Safari, дождитесь загрузки, выберите «Поделиться» → «На экран “Домой”» (на некоторых версиях iOS — «Добавить на экран “Домой”»), затем запустите приложение с иконки.
4. В установленном приложении добавьте «Молоко» в «Продукты» и «Мыло» в «Хозяйственные покупки». Переключите списки, отметьте товар, закройте и откройте приложение: товары и отметки должны сохраниться.
5. Удалите товар, снова откройте приложение и убедитесь, что он не вернулся. Включите авиарежим и повторите добавление/отметку/удаление и перезапуск.

Данные хранятся только локально: очистка данных сайта, удаление приложения или действия iOS по освобождению хранилища могут их удалить. Safari и установленное приложение могут иметь отдельное хранилище — проводите основной тест в установленном приложении. Синхронизации между устройствами нет. Для теста используйте обычный режим Safari.

## Структура

- `src/data/` — IndexedDB, схема базы версии 1 и операции сохранения.
- `src/domain/` — типы списков, создание и упорядочивание товаров.
- `src/hooks/` — загрузка, последовательные изменения и обработка ошибок.
- `src/App.tsx`, `src/style.css` — адаптивный интерфейс, крупные элементы управления и safe-area iPhone.
- `vite.config.ts`, `public/` — PWA, кеширование ресурсов и иконки.

Одновременное редактирование из нескольких окон не синхронизируется в реальном времени: для обновления другого окна нужна перезагрузка. Siri, перевод, архив, сервер и авторизация в v0.0.1 не входят.

## Результаты проверки v0.0.1 в облачной среде

- `npm test`: 3 теста прошли.
- `npm run build`: TypeScript и production-сборка прошли; manifest и service worker созданы.
- `npm audit`: уязвимостей не найдено на момент проверки.
- `npm run test:e2e -- --project=mobile-chromium`: прошёл весь сценарий, включая перезагрузку без сети и сохранение изменений в офлайн-режиме.
- WebKit загружен, но запуск в этой среде заблокирован отсутствующими системными библиотеками (GTK4, Graphene и другими). WebKit и настоящий iPhone пока не проверены. На машине с системными зависимостями используйте `npm run test:e2e -- --project=iphone-webkit`.
