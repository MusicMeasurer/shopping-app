## B1 — проверка 24-часовой блокировки на iPhone (ревизия db3a42b)

**Полигон:** [версия `db3a42b`](https://musicmeasurer.github.io/shopping-app-preview/integration/?v=db3a42b); [успешный Pages run `45256790819`](https://github.com/MusicMeasurer/shopping-app-preview/actions/runs/45256790819). **B1 пройден 24.11 в двух сценариях Safari, без замечаний**. Тестовая Supabase в 20:13 UTC 23.11 подтвердила одно активное ограничение до 24.11 **06:34 UTC**.

1. До конца ограничения открой полигон на iPhone в **активном несвязанном локальном профиле**. Открой меню профиля → «Зарегистрироваться» (в связанных профилях этой кнопки нет по согласованному правилу).
2. Введи email **уже удалённого тестового аккаунта**, пароль длиной не менее 8 символов два раза (пароль можно использовать произвольный тестовый). Подтверди регистрацию.
3. Ожидается сообщение: «Регистрация с этим адресом временно недоступна. После удаления аккаунта повторная регистрация возможна через 24 часа с момента завершения удаления». Не должно быть экрана ввода кода, не должно быть новой регистрации.
4. По возможности повтори на том же iPhone в **приватной вкладке Safari** — это отдельная чистая история браузера, без входа в старый аккаунт; результат должен быть таким же. Не требуется второе физическое устройство.
