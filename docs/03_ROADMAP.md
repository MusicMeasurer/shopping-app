# 03 · Дорожная карта

**Редакция:** 2026-11-04 · этапы и приоритеты; без текущего статуса и истории испытаний.
**Назначение:** порядок внедрения и контрольные точки, без ежедневных инструкций.  
**Принцип:** статус «готово» означает проверенный результат, а не только написанный код.

**Порядок не является обещанием календарных дат.** E2/E3 приоритетны из-за требования мгновенного Siri-добавления; E4 может частично выполняться параллельно. При изменении порядка проверять зависимости и риски.

## Контрольные точки и зависимости
- **E1 → E2/E3:** пока нет надёжной публикации, большие изменения несут риск задержек. Временно можно готовить патчи, но не считать их опубликованными.
- **E2 → E3:** нельзя подключать Siri к незащищённому API; сначала модель доступа и безопасный способ аутентификации.
- **E3 → E8:** общая база и доступ пользователя создают основу для совместных списков, но сами по себе семейный режим не реализуют.
- **E4/E5/E6 → E7:** полный MVP не принимается без архивов, голоса и перевода, если объём не пересогласован.

## Оценка сроков

Срок полного MVP не утверждён. Оценивать после определения объёма и зависимостей следующего работающего результата.

## Управление изменениями
1. Определить затронутые FR/ADR и зависимые этапы.
2. Сначала обновить документ-владелец решения, затем только затронутые файлы.
3. В `05_DEV_LOG.md` записать решение и проверку, если они значимы.
4. Не менять готовность этапа на «готово» без результата проверки.




## Приоритет ближайшей разработки

1. **E2:** закрыть согласование авторизации, границы локальных/облачных данных, воспроизводимости базовой схемы и бесплатных ограничений по критерию раздела 8 `02_ARCHITECTURE.md`. E1 принят 04.11.
2. **E3:** подключить личный список PWA к безопасной облачной синхронизации и обеспечить фактическое добавление товара через Siri; принять результат на iPhone.
3. **E4–E7:** развивать пользовательские функции по зависимостям и согласованным критериям.
4. **E8:** вернуться к семейным приглашениям после базового пользовательского пути. Испытания миграции 017 не означают готовности E8.

Дорожная карта не дублирует журнал и не содержит отдельного «текущего этапа». Фактическое состояние восстанавливается по GitHub и результатам испытаний по запросу.
