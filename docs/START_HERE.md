# С чего начать работу над ShoppingApp

Открывай этот файл из ветки `main` в начале каждой задачи по приложению, в том числе в новом чате. Действующие процедуры — в [рабочих инструкциях](04_WORK_INSTRUCTIONS.md), история решений и проверок — в [журнале](05_DEV_LOG.md).

## Куда идти

| Задача | Где работать |
|---|---|
| Продолжить обычную разработку | [`feature/e4-accepted-reintegration`](https://github.com/MusicMeasurer/shopping-app/tree/feature/e4-accepted-reintegration). С неё начинать согласованные доработки приложения. |
| Проверить приложение на полигоне | [Интеграционный полигон](https://musicmeasurer.github.io/shopping-app-preview/integration/). Публикация из отдельного репозитория [`shopping-app-preview`](https://github.com/MusicMeasurer/shopping-app-preview), база `shoppingapp-migration-lab`. |
| Открыть чистовую версию | [Основной адрес](https://musicmeasurer.github.io/shopping-app/). Исходник публикации — `main`, база `shoppingapp-security-lab`. |
| Найти Siri, черновики приглашений или прежнюю версию | [Указатель сохранённых версий](BRANCH_ARCHIVE.md). Перед возобновлением отложенной работы сверить её с текущим приложением. |

## Состояние на 19 ноября 2026

- **Принято на iPhone:** правки интерфейса E3/E4 из [`ec9b1b5`](https://github.com/MusicMeasurer/shopping-app/commit/ec9b1b52840a6710b463649976b03ed57c1efb17). Этот же исходник закреплён за интеграционным полигоном.
- **Рабочая ветка:** контрольная точка [`55da053`](https://github.com/MusicMeasurer/shopping-app/commit/55da053a5de467e6fd1e2bab0353cfef97be1509) включает принятую версию и отдельную запись проверенного SQL. При начале задачи сверяй последний коммит ветки с этой точкой.
- **Чистовая публикация:** [`cbdbfd5`](https://github.com/MusicMeasurer/shopping-app/actions/runs/44395809981). Две из трёх пользовательских проверок прошли. Открыт дефект синхронизации между устройствами: после отметки товара на одном устройстве повторное открытие приложения на другом показывает ошибку обновления списков. Подробности в [журнале](05_DEV_LOG.md).
- **Следующий этап разработки:** зафиксированы новые требования к профилям, карточкам и регистрации. Предлагаемый порядок работ — в [дорожной карте](03_ROADMAP.md). Исправление синхронизации собрано в рабочей ревизии [dbf3ecf](https://github.com/MusicMeasurer/shopping-app/commit/dbf3ecf6fcefdfdacc9982ef2f5f01fd0f13b0b3) и ожидает приёмки на полигоне. Илья подтвердил, что новый обычный чат нашёл рабочую ветку через эту страницу. Запись правок и просмотр результатов CI из обычного чата ещё не проверялись.

Обновляй этот раздел при смене рабочей ветки, публикации, приёмке или согласовании следующей задачи. Записывай основания и результаты в журнал.
