# 02 · Архитектура данных и ресурсов — актуализация E3
Дата: 2026-11-07. Дополнение к архитектуре от 2026-11-04.

## Реализованная ветка (ещё не production)
- React/TypeScript/Vite PWA, IndexedDB; гостевые и аккаунтные данные разделены.
- Supabase Auth с проверкой действующей учётной записи; обнаружение собственных облачных списков и явная проверенная привязка.
- Аккаунтные изменения в привязанном списке атомарно записываются локально вместе с долговечной очередью; версия и подтверждение операции сохраняются атомарно.
- Отправка через идемпотентный versioned RPC; возобновление после перезапуска и сигнала `online`, защита при выходе из аккаунта и от параллельной отправки.
- Консервативное согласование: импорт только новых облачных товаров после проверки; конфликты не перезаписываются; серверные удаления требуют просмотра и отдельного подтверждения, локальные проверки выполняются в транзакции.
- Нет автоматического переноса гостевых данных, автоматического удаления по tombstone или гарантированной фоновой синхронизации iOS.

## Проверенные границы
- CI: E3 #370 и E2 #211 успешны.
- Реальный изолированный Supabase: E3 disposable cloud integration #5 успешно проверил отправку, повтор, конфликт версий и tombstone review.
- В лаборатории `gmrqeubhotjpmtwokfeq` исправлена RLS SELECT policy `items_read`: `TO authenticated USING (can_access_list(list_id))`, чтобы владельцу были видны удалённые строки. Запрос активных товаров отдельно фильтрует `deleted_at IS NULL`; запрос tombstones — `IS NOT NULL`.
- Исправление зафиксировано в `docs/E3_TOMBSTONE_RLS_PATCH.sql` для контролируемого переноса. Production не изменён. Security advisors требуют отдельного анализа предупреждений по SECURITY DEFINER.

## Целевая, пока не реализованная граница Siri
Siri / Apple Shortcuts → защищённый приём команды → проверка полномочий → целевой облачный список → синхронизация с локальной PWA. Открытие URL в Safari не означает запись в IndexedDB установленной PWA; безопасность и доступность при блокировке требуют реального испытания. Секретные ключи не размещать в Shortcut или клиенте.

## Оставшиеся решения перед E3
- Реализация безопасного Siri quick-add, включая поведение при блокировке.
- Приёмка iPhone offline/restart/online и синхронизации без ручного импорта.
- Контролируемый выпуск проверенной RLS-политики и review безопасности, затем отдельное разрешение на публикацию.
