# E4 · Приёмка на физическом iPhone (черновик, без публикации)

Дата подготовки: 2026-11-08. Ветка: `feature/e4-lists-archive`, PR #6. Статус: **ожидает отдельного согласования тестовой публикации и ручной приёмки**. CI не заменяет физический iPhone.

## Границы
- Не изменять `main`, основной GitHub Pages, production Supabase или пользовательские данные.
- Для ручной проверки использовать отдельную тестовую сборку и отдельное хранилище браузера; адрес и способ публикации согласовать заранее.
- До проверки зафиксировать, какие данные должны сохраняться; не очищать существующие данные на основном сайте.

## Приёмочные сценарии
1. **Первый запуск:** видны «Продукты» и «Хозяйственные покупки». После закрытия и повторного открытия они доступны.
2. **Товары:** добавить несколько строк: `Молоко 2 л`, `Мука 1,5 кг`, `Сахар 2`; убедиться, что последняя запись не разбирается догадкой. Изменить название, количество и единицу, отметить купленным, снять отметку, удалить отдельный товар.
3. **Постоянный список:** создать, переименовать, заполнить, завершить с подтверждением. Список остаётся активным, очищается для следующей покупки, завершённая версия появляется в архиве.
4. **Разовый список:** создать, заполнить, завершить с подтверждением. Активная версия исчезает, архивная сохраняется.
5. **Изменение типа:** разовый → постоянный → разовый с товарами; после перезапуска тип и товары сохранены. Завершение использует текущий тип.
6. **Удаление:** удалить активный список после предупреждения. Его активные товары удалены, ранее созданные архивные версии сохранены. Проверить также один стартовый список: он не должен самовосстановиться после перезапуска.
7. **Архив:** просмотреть несколько завершённых версий одного постоянного списка; проверить названия, количество, единицы и сохранение после повторного запуска.
8. **Офлайн:** после первого открытия отключить сеть, добавить и изменить товар, закрыть и открыть установленную PWA, убедиться в сохранности; затем вернуть сеть. Это **локальная** проверка E4, не проверка облачной синхронизации E3.
9. **Ошибки и удобство:** отменить подтверждение завершения/удаления; проверить длинные названия, пустой ввод, мобильную клавиатуру, доступность кнопок и отсутствие потери введённого текста.

## Критерии
- Не теряются товары, их свойства и архив при обычных действиях, перезапуске и локальной офлайн-работе.
- Различие постоянного и разового списка соответствует согласованным правилам.
- Нет блокирующих дефектов, непонятных необратимых действий или повреждения локальных данных.
- Итоговые статусы FR-002…FR-005 повышать до «проверено на iPhone» только после фактической ручной приёмки.
